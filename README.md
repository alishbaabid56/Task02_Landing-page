# NOVA — Responsive Landing Page

A modern, responsive landing page designed and developed as part of **Aptura Tech Solution Batch 3 Internship — Week 1, Task 2**.

NOVA is a futuristic digital experience concept focused on clean visual design, smooth animations, responsive layouts, and interactive UI elements.

---

## 📌 Project Overview

NOVA is a modern landing page built with a dark, minimal, and futuristic visual direction.

The goal of the project is to create an attractive and responsive web experience while following modern frontend development practices.

The landing page includes animated sections, interactive navigation, responsive layouts, and smooth transitions across different screen sizes.

---

## 🎯 Task Objective

**Task 2: Build a Responsive Landing Page**

The objective of this task is to design and develop a responsive landing page using industry best practices.

The project focuses on:

- Modern UI/UX
- Responsive design
- Clean component structure
- Smooth animations
- Interactive elements
- Mobile-friendly navigation
- Reusable React components
- Professional visual presentation

## 🎬 Animation & Interaction

Framer Motion is used throughout the interface to create smooth and engaging interactions.

Animations include:

* Page element entrance animations
* Navbar reveal animation
* Staggered navigation animations
* Mobile menu transitions
* Hover animations
* Button interactions
* Section reveal animations
* Animated background glow
* Back-to-top interaction

The animations are designed to enhance the experience without making the interface difficult to use.

---

## 📱 Responsive Design

The landing page is designed to work across:

* Desktop
* Laptop
* Tablet
* Mobile

Responsive layouts are implemented using Tailwind CSS breakpoints.

The navigation also changes into a mobile menu on smaller screens to maintain usability and accessibility.

## ⚡ Installation & Setup

Clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

Navigate to the project:

```bash
cd nova-landing-page
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open the local development server in your browser:

```text
http://localhost:3000
```
